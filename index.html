About Me

Who I am and what I work with

I'm an Android developer who also builds the backends behind the apps. Most of my work is Kotlin and Jetpack Compose on the client, structured around MVVM and clean architecture — and Spring Boot or PHP on the server, secured with JWT and backed by MySQL.

Working on both sides has been the most useful thing I've done. When I built Laundry Hub, I designed the API contract and consumed it from three different app flavours — so I know exactly where the two sides tend to disagree, and how to keep them honest.

Lately I've been exploring Kotlin Multiplatform, sharing one codebase across Android, iOS, and Desktop. I like problems where the hard part isn't the UI — exact alarms that survive Doze mode, puzzle generators that guarantee a unique solution, real-time messaging over WebSocket.

    Learning to build

    Started learning Android and backend development, working through the fundamentals of Java, Kotlin, and how a client and server actually talk to each other.

  2. 2024 — First web project

    Java on the server

    Built HelloBlog, a traditional Java web application. First taste of handling requests, templates, and persistence end-to-end.

    • Java
    • JavaScript
  3. 2025 — Compose, seriously

    From UI to architecture

    A run of Android apps — Weather, Meditation UI, Calculator, then Cryptocurrency Info. The jump happened here: from drawing screens to structuring them, adding Retrofit, Hilt, and MVVM.

    • Kotlin
    • Jetpack Compose
    • Retrofit
    • Hilt
    • MVVM
  4. Early 2026 — Depth

    Offline-first & full-stack web

    Notepad brought Room, StateFlow and the repository pattern. Pathshala Bazar was a whole web marketplace in hand-written PHP MVC — auth, messaging, admin, and security done properly with CSRF tokens and prepared statements.

    • Room
    • StateFlow

    • MySQL
    • Bootstrap 5

    Both sides, and every platform

    Laundry Hub — a three-role marketplace with a Spring Boot API, Stripe, and Maps. RealTime RoomChat — Android and React clients on one WebSocket backend. Sudoku KMP — one Kotlin codebase on Android, iOS and Desktop. TaskFlow and Arduino Controller round it out.
